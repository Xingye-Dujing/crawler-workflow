# AI 分析 · 数据处理 · 可视化

> 本文是采析绘文档的一部分，返回总览见 [README.md](../README.md)。断点续跑与运行记录见 [workflow.md](workflow.md)。

AI 分析（双提供方、情感/倾向/NER/关键词等）、通用数据处理与事件研究算子、文献计量、跨源融合，以及可视化与 LaTeX 出图。

## AI 分析
- **双提供方与逐节点模型**：本地 Ollama 或 OpenRouter（免费模型一键拉取、连接测试）；模型、批量行数、截断长度在 AI 面板配置，OpenRouter Key 只存浏览器 localStorage，不落服务器。AI 面板选运行级默认模型；每个本地 Ollama 分析节点（清洗/情感/倾向/NER）可单独挑模型，默认“跟随全局”；OpenRouter 运行不提供该下拉。
- **BERT 的两个运行时**：`sentiment`/`emotion`/`tendency` 的 `bert` 模式都走 `analyzers/sentiment.py` 的同一个加载器，返回 `{'label','score'}`。顺序：有 `torch`+`transformers` 用它们（有显卡上显卡），否则用 `onnxruntime`+`tokenizers` 跑导出的 ONNX（Windows/macOS 桌面版走这条，包里无 torch），两者都不可用才按名拒绝或降级；日志写明 `runtime=` 与 `precision=`。导出与对齐脚本见 `ml_train/scripts/export_onnx_bert.py` + `ml_train/scripts/eval_onnx_parity.py`（默认发 fp16；int8 是显式选项，会让部分行改判定）；模型本体不进应用包（[desktop/README.md](../desktop/README.md)）。下文“缺 torch/transformers 就降级”统一读作“两种运行时都不可用”。
  选型理由见 [why_finetuned_bert.md](why_finetuned_bert.md)。
- **情感分析（三模式）**：`llm` 逐行、`ml`（sklearn TF-IDF + 逻辑回归）或 `bert`。标签集是 SMP2020-EWECT 六类（`Anger`/`Fear`/`Joy`/`Neutral`/`Sadness`/`Surprise`）。`llm` 的无法解析回答记 `未判定`（置信度留空），不写 `Neutral`；ML 通路统一 jieba 词 + 停用词去噪 + `class_weight=balanced` 逻辑回归（子线性 TF），`build_tfidf_pipeline(char_features=True)` 可并字 n-gram，`/api/analysis/train` 与 `ml_train/` 共用。`bert` 是默认（未点名时取注册表 emotion op 的默认模型），填本机 HuggingFace 目录即整列分批推理（`batch_size`、`max_length` 默认 512），`pipeline('text-classification')` 读 `id2label`，换任何六类模型都不用改分析器；缺栈或无注册模型时执行器自动降级到 `ml` 并打印实际模式，分析器被直接当 `bert` 调用仍按名拒绝，读不出的行留空。
  训练脚本 `ml_train/scripts/train_emotion_bert.py`。
- **情感极性（四模式）**：输出 `sentiment`（`positive`/`negative`/`neutral`）与 `score`（0–1 正极性概率），是独立操作而不是“情感分析”的第三个开关。`snownlp`（无模型/GPU/API，bert 跑不动时的回退）用随包极性模型，加“判定为正面的下限/判定为负面的上限”两个节点参数（落在之间记中性，默认 0.6/0.4），`score` 始终保留原始概率；`ml` 从已标注行拟合 `data/models/sentiment.pkl`；`llm` 与情感/倾向共用批量、缓存与检查点；`bert` 是默认，缺栈/无模型时执行器自动降级到 `snownlp` 并打印实际模式，分析器本身被直接当 `bert` 调用仍按名拒绝，多模型对比不降级。BERT 头是正/负二分类，`neutral` 只由 `label_for_score` 按阈值卡出。
- **倾向性分析（三模式）**：`llm`（无法解析记 `未判定`，不写 `Objective Statement`）、`ml`、`bert`（默认；六类传播立场，与情感/情绪同一后端）。倾向没有公开语料：`ml_train/scripts/distill_tendency_labels.py` 用节点自己的 `llm` 在真实微博打标签，再由 `train_tendency_bert_v1.py`/`train_tendency_bert_v2.py` 微调 `hfl/chinese-roberta-wwm-ext`；`pipeline` 直接读 `id2label`（标签含空格/斜杠原样匹配），换任何六类模型都不用改分析器。缺栈/无模型降级到 `ml` 并打印，多模型对比不降级；不认识的标签留空。
- **微调模型注册表**：`data/model_registry.json` 登记 `{name, path, operation, desc}`；`operation`（`emotion`/`tendency`/`sentiment`）决定候选节点与未点名时的默认模型，路径相对仓库根。`GET /api/models` 送出后，节点 `bert` 面板列出已注册模型的复选框，按显示名勾选，写入 `bert_models`（逗号分隔的路径，运行按路径加载）；下方保留原始路径框，二者以 `bert_models` 优先。文件缺失/损坏时复选框整组消失、路径框仍在——注册表是可选加速器，不是运行前提。
- **多模型对比**：`bert` 模式勾 ≥2 个模型时对同一文本列逐模型各跑一遍，输出长表：原表每行 × 每模型一行，新增 `模型`（显示名）与 `原行`（跨模型对齐），标签/置信列沿用各操作现名；只勾 1 个时保持原形状（就地加两列）。选择按去重排序存，点选顺序不改指纹；`bert_models` 是选数据的输入，进指纹、不进 `_VOLATILE_PARAMS`。可视化：模型×标签分布用热力图（`x_field=模型`、`y_field=标签列`）；模型间一致率用 `model_agreement`（按 `模型`/`原行`/标签列算两两相同百分比，model×model 方阵热力图，仅 ECharts）。缺列按名拒绝，不足 2 模型也拒绝而非画 1×1 空图。
- **其余分析**：语义清洗过滤广告/无关/低质（LLM 判定）；关键词 TF-IDF / TextRank（jieba）；文本聚类 K-Means/DBSCAN（`analyzers/clustering.py` 接受 `kmeans`/`kmeans++`，`n_init='auto'`、`random_state=42`，同表两次跑出同分组；`dbscan` 按 `eps`/`min_samples` 自动定簇并标噪声）；NER 双模式（正则四类、或 LLM 抽取，可只保留某几类）；异常检测 Isolation Forest（少于 5 行或无可用数值列时明确报错，不给每行填 0 分）；相关性 Pearson/Spearman/Kendall（点名的列全是文本时报错并点名，混选只算可用列并说明跳过）；模型训练从 LLM 标注一键训传统 ML（`ml_train/scripts/train_sklearn_ml.py`）。
- **显著性检验（跨组比较）**：一个类别列分组、一个数值列取值。`ttest`→Welch's t（`equal_var=False`，恰好两组，面板与标签都写 Welch）；`anova`→单因素方差分析（≥2 组，F）；`mannwhitney`→Mann-Whitney U（两组）；`kruskal`→Kruskal-Wallis H（≥2 组）。p 值取 scipy 真实分布 CDF（scipy 是直接依赖）。输出一行，列名固定为下游合同：`method, group_column, value_column, statistic, p_value, n_groups, group_sizes, significant_005`（固定 α=0.05）；`group_sizes` 先丢空分组与转不成数值的行，报“测了多少”。缺列、组数不对（如 ttest 给三组，句里点名试 ANOVA/Kruskal-Wallis）、方差为零等一律按名报错，绝不回空表。

## 数据处理
- **通用分析节点**：算子与面板 `panels/node-analysis.js` 的 `ANALYSIS_OPS` 一一对应——去空值 `drop_null`、填充空值 `fill_null`、去重 `drop_duplicates`、近重复去重 `dedupe_similar`、条件筛选 `filter_rows`、选择列 `select_columns`、重命名 `rename_columns`、去除空白 `strip_whitespace`、类型转换 `convert_type`、排序 `sort_rows`、采样 `sample_rows`、分组聚合 `groupby_agg`、表关联 `join_tables`、反向筛选 `anti_join`、列计算 `column_calc`、数值分箱 `bin_column`。去空值可选“任一列为空/全部列为空”，填充可选给定值或 ffill/bfill，分箱可填箱数或边界加标签。算子被拒（不存在的算子、文本列求和、非数字比较）时节点失败并写原因，不回空表。
  表关联/反向筛选的表角色与“重爬缺口”闭环见 [workflow.md](workflow.md#双表角色与重爬缺口)。
- **分词与清洗**：jieba 对任意文本列分词，输出词频对，供导出或词云；旧画布的独立“分词”节点仍可执行，新建用“处理 → 分词”。清洗节点 `regex` 模式不用模型，剥转发链（`你的评论//@某人:原文` 只留自己那段）、`@提及`、`#话题#`、链接与 `O网页链接`/`展开c`、`[表情]`，整行只剩这些则判“删除”；它不判断主题相关性（那是 `llm` 模式）。源文本列原样保留，结果写在 `cleaned_text`；留空=默认 `llm`。
- **关键词（自建语料 IDF）**：jieba 内置 IDF 来自新闻语料，微博口语会排错位；这一档用你自己的表拟合 IDF。另可填词性过滤（如 `n,vn,v,a`），去掉“转发/哈哈/回复”。
- **网暴言论识别（`aggression`）**：研究对象是暴力言论而非负面情绪。四类特征：谩骂、人身攻击、隐私披露（手机号/身份证/住址/人肉开盒）、造谣转述，输出 `aggression`（none/mild/severe）、`aggression_score`、`aggression_hits`。默认词库模式：无模型、不花钱、同表同结果；它是召回器不是判定器（换说法的攻击看不见且无法度量），词表放在代码里让不足可见；隐私披露权重高于谩骂，辟谣用词（造谣/辟谣）不算暴力。要覆盖委婉语/谐音切 `llm` 模式。缺文本列直接抛错，不回空列。
- **事件研究套件**：`extract_time` 从时间列派生 `日期`/小时/星期等（解析不了的相对时间留空，不猜年份）；`bin_time` 用“边界+阶段名”打生命周期标签（左闭右开、按自然日），并写数字 `stage_order`（首阶段=1）——阶段列是有序 categorical，但每过一节点表格会被 `pd.DataFrame(records)` 重建回字符串，中文阶段名按码点排序会把“二次爆发期”排到“发酵期”前；只有数字能跨过节点边界。`suggest_stages` 读每日发帖曲线峰谷，打印可直接粘进上一步的 `edges`/`labels`（峰=连续若干天 ≥ 比率×日常中位数，短窗口并入邻居并警告）。任何按阶段分组/排序的步骤都取阶段列的顺序或 `stage_order`/时间列，否则按名拒绝，绝不按名字猜。
- **主题模型**：`topic_model` 及距离图/显著词/分阶段默认 `method=auto`：有 sentence-transformers 等可选包就用句向量 + KMeans（默认 `BAAI/bge-small-zh-v1.5`），否则 LDA，两者都在控制台写明实际方法；显式 `embedding` 而无编码器则按名拒绝，`lda` 强制 LDA。四种主题步骤共用同一套 `method` 且输出列名逐字不变（`pc1/pc2/prevalence_pct` 与 `term/overall_freq/within_freq`）；embedding 复用同一份 CountVectorizer 词矩阵，只换“文档→主题”指派；困惑度是 LDA 的量，embedding 时如实留空（nan）。
  `topic_by_stage` 逐阶段建模，输出“每(阶段,主题)一行”的宽表（`阶段/主题编号/特征词/权重/该主题帖子数/困惑度/代表文本`）并写 `stage_order`；主题数可统一或逐阶段列举，阶段先后来自阶段列或指定时间列，都没有则拒绝。`topic_label` 每主题问一次模型，把“不超过 15 字”写进 `主题概括`（默认任一失败即节点失败，可切“留空继续”；无模型一开始就拒绝；答案进 `runs.db` 的 `llm_cache`）。
- **主题/情感演化**：`sentiment_evolution` 按分组列算积极/中性/消极数量与占比、情感指数 `(积极−消极)/总数 ∈ [-1,1]`、热度 `volume_pct` 与可选强度 `|score−0.5|×2` 均值。`topic_map` 一行一主题给 `topic/pc1/pc2/prevalence_pct/doc_n/feature_words`，坐标是主题词分布的 Jensen-Shannon 散度经经典 MDS 降到二维（符号固定，同表永远同图）。`topic_salience` 一行一(主题,词)，给 `overall_freq` 与 `within_freq`，按 `λ·log p(w|t) + (1−λ)·log(p(w|t)/p(w))` 排序（λ=1 主题内、λ=0 相对全库，用值随表打进控制台）。
  `topic_timeline` 用特征词 Jaccard（默认 0.5）跨阶段追踪，输出 `首现阶段/峰值阶段/末现阶段/覆盖阶段数/阶段路径/规模合计/is_secondary`（`is_secondary`＝不是开场主题且峰值在首现之后）。`topic_flow` 把相邻阶段主题的 JS 散度换成相似度 `1/(1+d)`，过阈值才出一条边（`source/target/similarity/from_stage/to_stage`），一条都不到时拒绝并报实测最相似的一对。
  `topic_coherence` 对 `min…max` 逐个拟合，给困惑度与 NPMI（发表口径 C_v 的一部分，不可直接对论文数字），大语料默认抽 2000 篇。`cooccur` 候选词取本表 TF-IDF，数同现输出 `source/target/value`，候选上限 120，超了拒绝。
- **其他事件算子**：`reply_graph` 用评论的 `楼层`/`父楼层` 把回复对回顶层评论作者，输出 `src_author/dst_author/weight`，一条都对不上则拒绝。`compare_platform` 按 `platform` 列每平台一行（`n` 加一个可选数值列的聚合）；该列由输出节点合并多个爬虫时统一盖下，缺列拒绝。`cluster_label` 读聚类标签列与原帖文本，每簇问一次模型写摘要；`cluster_review` 是文献计量版，喂给模型的是该簇已有度量（LLR 标签、节点数、代表节点、年份跨度），要 3–5 句研究前沿，`on_fail=fallback` 的句子在格子里写“未经模型”。
  `bot` 按作者读整表：与他人高度雷同（复用 SimHash，跨账号才算）的文本占比 + 相对全库中位的发帖突发，写 `bot_score/bot_level/bot_evidence`，是召回线索不是判决，缺 `评论者`/`评论时间`/`正文` 任一列都拒绝。
  `forecast` 把曲线形状往后推若干期（四种手算方法，不引 statsmodels；列必须能解析成日期）。`alert` 把“提前干预”落成规则（`转向`=连续 N 期同向超阈、`升温`=强度每步上升超阈，都要热度还在），没触发也出一行 `未触发` 并带实测最大幅度。柱状/折线/双轴折线可加事件标注（`2024-05-19=公安通报;…`，标签须与横轴取值一字不差，对不上拒绝并列出可选值；Matplotlib 明确拒绝）。
- **去重三层**：`drop_duplicates` 有 `exact`（逐字）与 `normalized`（忽略链接/@/话题/表情，能识别水军改写）；`dedupe_similar` 用 SimHash 按语义指纹距离分组抓“改一个词的转发”。归一化只用于比较，落库仍是原文；距离默认 8 位，上限 15，往上提召回降精确率。
- **文件、导出与报告**：上传/粘贴的文件注册为数据集（内容哈希寻址、zlib 压缩存库），已存工作流可重载自己的输入，无引用且长期未用的自动清理；“数据集管理”可逐个改名/删除（被已存工作流引用的当场拒绝），面板头“清空”连被引用的一并删（确认框里写明）。输出节点支持 CSV/JSON/Excel/TXT/HTML/Markdown/Parquet（parquet 需 pyarrow，属可选依赖，缺则拒绝并提示 `pip install pyarrow`）。工具栏“生成报告”把一次运行的每张表与服务端渲染的图拼成自包含 HTML（样式与图片内联、离线可看可打印），可选“附 AI 结论”（只据统计数字写一段）与“生成并导出 PDF”（用本机无头 Chrome 打印，找不到就少一个 PDF）；报告只经 `/api/report/view` 提供并带禁脚本 CSP。

## 文献计量
CiteSpace 风格的知识图谱以 Bibliometrics 节点接入，是普通表格节点：上游可为 Upload（CSV/Excel/JSON/CNKI/CSSCI）或爬虫；列映射把任意表接成网络，CNKI/CSSCI 只是默认列名。净室重写（Kleinberg 突现、PFNET、谱聚类、LLR 等公开算法），不含 CiteSpace 代码或 JCR 基线。
- **导入**：格式注册表只识别实测过的导出件——CNKI 三种按钮（RefWorks `.txt`、NoteExpress `.net`、EndNote `.enw`）、CSSCI 文本、WoS（纯文本/Excel/RIS/BibTeX）、Scopus CSV（中英文表头、`Article number`/`Art. No.`）、Dimensions CSV（Export full record，先跳版权横幅）、Lens 学术文献集合 CSV、PubMed（Medline 文本与 CSV；无 XML）、RIS、BibTeX、EndNote。Lens 专利集合按名拒绝，其 `References` 是记录 ID 而非引文，故共被引/耦合只能用带引文文本的 WoS/Scopus/CSSCI；Lens 无单位列，机构/国家网络按名拒绝。规范化列为 `记录ID/题名/作者/作者单位/来源期刊/年份/卷/期/页码/关键词/摘要/参考文献/DOI/格式`，按数据追加 `国家/学科/引用次数/使用次数/基金/文献类型/语言/引文`。
  WoS 的 Excel 缺 Cited References 整列，引文网络与突现要用纯文本 + 全记录与引用文献。
- **实体与网络**：关键词/作者/机构/国家/学科/主题词/基金共现，文献·作者·期刊共被引，文献耦合，来源期刊耦合；CiteSpace 的 `Source`/`Grant`/`Article` 对应 `source`/`grant`/`article`。按年切片（`slice_years`），每片按 TopN/Top%/g-index/阈值三元组选后合并；支持 look-back、最低 TC/usage、citation expansion（0–2 阶，上限 500 条/文献并播报）、cosine/Dice/Jaccard/association、`counting` 整次或分数计数（`fractional` 均摊信用；耦合类拒绝）、每节点最大连边 + LRF、cc/ccv 过滤、最大连通分量；剪枝 none/MST/Pathfinder（作用域 `slices` 逐片或 `merged`），Pathfinder 三参数 `pathfinder_r`（1/2/inf）、`pathfinder_lmax`（0=不限）、`pathfinder_dmax`（1=全留）。
  规模超预算按名拒绝并写出节点数/层数/运算量。
- **指标与聚类**：度、中介中心性（节点多时按 500 源点采样并播报）、特征向量中心性（按连通分量）、PageRank、Sigma = `(中介中心性+1)^突现强度`；有 `引用次数` 追加 `总被引/H指数`，有 `使用次数` 追加 `使用次数合计`。归一化 Laplacian 谱聚类，簇数留空按特征值间隙自动选；模块度 Q、轮廓值写运行摘要；标签 LLR/LSI/MI/TF-IDF，`label_source`（`all`/`title`/`abstract`/`keywords`/`author`）显式来源缺列运行前拒绝。突现用两状态 Kleinberg Viterbi 按逐年文档数算，每节点留最强区间，另写 CSV；耦合类禁止突现。
- **结构变异（`variation`）**：度量相邻两切片间一个节点连接模式的移动量——两期连边强度分布的 Jensen–Shannon 散度（比特）；用 JSD 而非裸 KL，因为“某邻居出现/消失”会让 KL 无穷。`variation_min` 默认 0.05 bit；只有两期都有连边的节点计分，切片不连续不跨缺口比较。`output_shape=variation` 输出 `节点/起始年/结束年/结构变化/前邻居/后邻居/新增邻居/消失邻居`；少于两切片或耦合类拒绝。
- **叠加与人工校正**：`sentiment_column`/`topic_column` 填上游已写出的标签列，每节点追加 `情感倾向`+`情感分布`（或 `主导话题`+`话题分布`）；分布是提及该节点的文档里各标签篇数的规范 JSON，主导取最多者、并列按标签文字定序；分母只含有标签文档（空白是没有判断，不是中性）；填不存在的列或整列无标签都在运行前拒绝。图 `sentiment_overlay`（100% 堆叠横条）与 `topic_overlay`（节点×话题热力图），只画前 20 节点/12 话题并写明省略数。`aliases`（`规范名=别名1|别名2`）与 `exclude_values` 在建图前合并/移除节点并计入指纹；`cluster_labels`（`#簇号 = 标签`）在自动标签后覆盖簇名；填了人工簇标签却没开聚类则运行前拒绝。
- **输出与图**：默认 `output_shape=nodes`，一行一节点，固定列 `节点/类型/频次/首年/末年/年份序列/度/中介中心性/特征向量中心性/PageRank/Sigma/x/y/连接`；开聚类追加 `聚类/聚类标签/轮廓值`，开突现追加 `突现强度/突现起始/突现结束`；`连接` 与 `年份序列` 是规范 JSON。还可输出 `edges`/`clusters`/`bursts`，`dual_map` 输出 `map/source/target/weight/label/x/y` 叠加表（`map` 取 `journal`/`category`/`overlay`，需 `basemap_dataset_id` 指向自备“期刊—学科”两列表，缺则拒绝）。
  图：`knowledge_graph`、`circular`、`cluster_timeline`、`landscape`、`burst`、`timezone`、`biblio_heatmap`、`graph3d`、`variation`、`dual_map`、`geo_map`、`sentiment_overlay`、`topic_overlay`、`concentric`（按首次出现年份落环，内环最早，无年份的单独最外一环），均仅 ECharts；缺列/无连边/未开聚类/突现/变异/叠加时按名拒绝。十四类图都有 TikZ/pgfplots 与 booktabs 三线表，`emit_latex`/`emit_latex_table` 默认开；前端 `labelLayout` 按实际矩形避让，y 轴分类标签永不旋转。
- **按年份回放与跨 run 监测**：图谱与环形图每个节点带 `yearSeries`，节点按截至该年累计频次长大，连边在两端都出现的年份才出现；最后一帧与完整图逐字节相同，已存 PNG/SVG/LaTeX 仍是完整网络，只有 ECharts 图型有回放条。`biblio` 节点填 `watch_project` 后每次运行把网络存成该项目快照，并与上一次（或 `watch_baseline` 指定的）对比：节点/边增减、逐列属性变化、簇增减、突现起止、改过的参数，逐条打印并存 `<画布>-<节点>-watch.csv`。输出形态不是实体表、本次图谱为空都按名拒绝；`watch_*` 不进指纹也不写进快照参数。配合定时任务即是监测流水线。
- **地理图与底图**：`geo_map` 用 Natural Earth 1:110m Admin 0（public domain），由 `tools/build_world_geojson.py` 生成并随仓库分发（`backend/static/geo/world.json`，239 区域）：只留 `name/zh/iso/alt`、坐标两位小数，110m 缺的小国从 1:50m 补。名称解析走 `services/biblio/geo.py`（底图 → 导入器别名表 → 短桥表），`tests/unit/biblio/test_biblio_geo.py` 拿导入器能吐出的全部国名逐个比对；同一地区多种写法按地区求和。台湾、香港、澳门的几何并入中国（坐标拼接），图上点名“并入其他区域 N 处”。
- **第三方文件与边界**：`tools/vendor_frontend_assets.py` 取回并钉住 ECharts 5.4.3 / echarts-gl 2.0.9 / echarts-wordcloud 2.1.0、Literata 14 个 woff2（SIL OFL）与 DataV 中国省级底图 `backend/static/geo/china.json`，每个文件都有 SHA-256 断言；缺失时指名道姓（“图表库没有加载（/vendor/echarts.min.js）”，底图读不到就画进图里），真浏览器用例读 `performance.getEntriesByType('resource')` 证明没有请求离开本站（`tests/integration/test_ui_layout.py`）。
  默认产物 `<节点>_graph.graphml`、`_graph.gml`、`_graph.net`（Pajek）、`_graph.json`、`_nodes.csv`、`_edges.csv`，开聚类/突现另写 `_clusters.csv`/`_bursts.csv` 并登记到运行；`export_files` 可关，`dual_map` 只写表。CNKI 无被引次数与 CR，故无共被引/耦合/引用突现；双图基线由用户导入（样例 `samples/biblio/biblio_basemap_demo.csv`），不内置商业 JCR 数据。演示画布 `data/workflows/文献计量演示：CNKI 与 CSSCI 知识图谱.json`（14 张图；双图叠加与情感/话题叠加链默认关闭）；换机器时先上传 `samples/biblio/biblio_cnki_demo.txt` 与 `samples/biblio/biblio_cssci_demo.txt`，再在两个 Upload 节点重选。

## 跨源融合
- **`fuse` 节点**：把任意多张上游表折成一份规范记录表（`题名/作者/作者单位/来源期刊/年份/关键词/摘要/参考文献/记录ID/来源`）。每个角色是候选列列表按序尝试：文献 `关键词` 与帖子 `话题` 折进同一词表，下游 `biblio` 用默认列映射即可。年份从时间戳取四位，取不到为空（`keep_undated` 决定留不留）。`记录ID` 是内容身份（`来源#题名|第一作者|年份` 的哈希），与 `importer` 语义一致，增删父节点不改记录 id；同一来源里内容相同的第 2、3 行起把出现序号并入哈希（序号只跟该来源行序走），否则下游无法区分。不用 `metrics.records` 的位置序号（`来源#父序号-行序号`）当身份——两种用途都会失真。
- **来源是数据，不是猜的**：表内自带 `平台`/`来源` 列就逐行取；否则用 `source_labels` 为该父节点写的一行（`node-1 = 文献`）；再否则按父节点 id 登记。不会替没说过来历的表写“文献”。父节点无可用实体列或一个实体都没提出，按名拒绝并列出试过的候选。输入带 `来源` 时 `biblio` 输出多出 `来源`（出现在哪些语料，`;` 连接）与 `跨源`（是否多于一个）。
- **为什么不用 fan-in**：引擎多入线合并保留各表列名、把行拼起来，`关键词` 与 `话题` 会永远分居两列且没有来源信息；`fuse` 因此读 `upstream`（每个父节点及其行）而非 `current_input`，也不打印“第一条线是主输入”。`export_files` 打开时写 `fuse_records` CSV 并登记。

## 可视化
- **论文样式**：印刷安全配色（首色深板岩蓝）、衬线字体（Times New Roman + 宋体）、折线不平滑不填渐变、坐标轴细而可见、网格浅虚线；分类轴保留表格自身行序。密集分类轴（>12 值）旋到 45° 并强制显示每格（`interval: 0`）；力导向图先算定再画（`force.animate: false`）。
- **关系图与本地化**：`center_node` 填图中已有的词，只画它的 ego-network（该词 + 直接共现词 + 这些词之间的边），是真参数（进指纹、改变出图），留空画全部，填不存在的词按名拒绝。图例、series、轴名、tooltip 与从数据读出的分类值（`positive/negative/neutral`→正面/负面/中性、`Topic-1`→主题-1、`PC1/PC2`→第一/第二主坐标）都在显示层翻译（`services/charts/visualizer.py` 的 `_localize_label`）；库里与算子输出的列名、标签值不改。
- **停用词与图型**：LDA 特征词、显著词、共词网络、关键词节点、词云共用 `analyzers/stopwords.py`，表保守收录、域内实词保留。30 种图（`services/charts/registry.py` 的 `SPECS`）：柱状/折线/双轴折线/主题距离图/显著词图/饼图/散点/直方/箱线/热力/模型一致率/桑基/关系图/词云/中国地图，以及 14 类文献图（知识图谱/环形/聚类时间线/景观/突现/时区/聚类年份热力/三维/结构变异/双图叠加/情感叠加/话题叠加/国家地理/同心环）；ECharts 或 Matplotlib（双轴折线、主题距离图、显著词图、模型一致率、关系图与全部文献图仅 ECharts，选 Matplotlib 明确拒绝）；柱状/折线/双轴可加事件标注。
- **占比堆叠图 `stack_pct`**：横轴是分类，`堆叠字段` 填逗号分隔的若干列（每列一段，如 `积极占比,中性占比,消极占比`），每个分类归一到 100%（计数自动换算），横轴保留数据表阶段顺序，列名随语言本地化，两引擎都支持。
- **LaTeX**：每个可视化节点除出图外生成可被本机 xelatex 编译的 `data/exports/<节点标题>.txt`（standalone，可复制 figure 体进论文），pgfplots + TikZ + ctex + booktabs，仿宋、muted 配色、千分位、分类过多时 X 轴倾斜抽稀；主题距离/共词/桑基标签走白底圆角框 + 引线。`emit_latex_table` 另出 booktabs 三线表 `.txt`。LaTeX 生成失败只记一条具名日志，不影响出图。
- **编译节点与 PDF**：`compile` 节点上游只能是可视化节点，把其 LaTeX（图/三线表）合成一份 standalone 并编译成一个 PDF；再接输出节点落盘，可视化节点直连输出节点也能出 PDF。输出格式按上游锁定：上游是可视化/编译节点时只有 PDF。`xelatex` 按 OS 探测（`services/charts/pdf.py` 的 `XELATEX_PATHS`：Windows MiKTeX、Linux TeX Live、macOS MacTeX），也可在设置里指定；找不到只让该节点具名失败。编译失败读 `main.log` 而非 stderr，能点名就点名（缺 `ctex.sty`、缺 FangSong 字体）。
- **采集深度与 Chart Studio**：微信正文上限 `Config.WECHAT_BODY_MAX_CHARS`（默认 0，完整保留）；小红书数据源可设每篇评论预览数，`0` 真的跳过评论面板。画布内嵌 ZENVIZ 工作台，对任意节点/数据集的完整表自由创作，支持多数据源合并，成品 PNG 存回导出目录。
- **预览、看板与图片**：数据预览可翻页看真实行，“平台”列显示本地化名（`douyin`→`抖音`，库里存原 key，未知 key 回落原值），导出文件同样写本地化名（导出走 `DataExporter`，身份仍是原 key）。含评论节点时运行前提示“评论地区列可能为空”。仪表盘把全部 Visualize 节点拼成网格，重启/刷新后自动回填（图是数据行投影），无结果时灰字提示“尚无运行数据”（HTTP 200）。预览与看板每格可“存为图片”（ECharts 取 `pixelRatio=2` 白底 PNG，Matplotlib 存已拿到的图；没画过就说明先预览或跑完）和“全屏”（可拖拽改大小的浮层，优先复用屏上那张，否则重新请求且必带 `label_field`，关窗即 `dispose`）。
  实时统计展示情感/倾向分布与执行汇总。
